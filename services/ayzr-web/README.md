# AYZR Web — منصة ذكاء أسواق الذهب

موقع مركزي يعرض بيانات XAUUSD الحقيقية مع تحليل فني محسوب محلياً وتحليل نصي بالعربية.
الواجهة عربية بالكامل بتخطيط RTL.

## المصادر

| المصدر | الاستخدام | ملاحظة |
|---|---|---|
| [biquote.io](https://biquote.io/docs) | الشموع والسعر والتقويم الاقتصادي | الأساس. بيانات MetaTrader 5 حقيقية، بلا مفتاح |
| Yahoo Finance (GC=F) | احتياطي للشموع | يُستخدم فقط عند تعطّل biquote |
| llama.cpp + Qwen2.5-1.5B | التحليل النصي العربي | محلي بالكامل، لا يخرج أي بيانات |

### ملاحظات على biquote

- المعامل `interval` يقبل الصيغة الصغيرة فقط: `15m`، `4h`، `1M`.
  إرسال `M15` **يُتجاهل بصمت** وتُعاد شموع الساعة — لهذا يرفض الكود أي رد
  يأتي بفاصل مختلف عن المطلوب (`_fetch_biquote`).
- الشمعة غير المكتملة مُعلَّمة `isOpen: true`؛ يُحذف ما عَلَّمه المصدر بدل
  تخمين أن آخر صف هو المفتوح.
- `1w` تُرجع سلسلة فارغة، لذا `W1` غير معروض بدل عرض بيانات خاطئة.
- نقطة السعر: `GET /api/XAUUSD/` تعطي bid/ask/spread من MT5 مباشرة.

## التشغيل

```bash
pip install -r requirements.txt

# النموذج المحلي (منفصل)
/workspace/ai-runtime/llama.cpp/build/bin/llama-server \
  -m /workspace/ai-runtime/models/qwen2.5-1.5b-instruct-q4_k_m.gguf \
  --host 127.0.0.1 --port 8080 -c 4096 -t 4

# الخدمة
python3 -m uvicorn ayzr_web.main:app --host 0.0.0.0 --port 12000
```

## نقاط النهاية

| المسار | الوصف |
|---|---|
| `GET /api/health` | حالة الخدمة والنموذج |
| `GET /api/quote` | السعر الحالي bid/ask/spread + تغيّر اليوم |
| `GET /api/candles?tf=M15&limit=300` | شموع مغلقة |
| `GET /api/analysis?tf=M15&with_ai=true` | مقترح فني + تحليل نصي |
| `GET /api/news?limit=40` | التقويم الاقتصادي |
| `GET /api/timeframes` | الإطارات المدعومة |

عند تعطّل المصدر تُعاد `503` مع سبب واضح، وتعرض الصفحة «البيانات غير متاحة».
لا يُستبدل أي رقم بمُقدَّر.

## الإطارات المدعومة

`M1 M5 M15 M30 H1 H4 D1` — سبعة إطارات.

`W1` و `MN1` **غير مدعومين**: biquote تُرجع سلسلة فارغة لـ`1w`، و`1M` أخطر من
الفارغ — تُعيد شموع **دقيقة** بينما تعلن الوسم `"1M"`. الحراسة في `_assert_spacing`
تقيس التباعد الفعلي وترفض أي سلسلة لا يطابق إطارها، وتعمل عند نقطة الاختناق
التي تمرّ منها كل المصادر.

## الأصول البصرية

`python3 scripts/make_assets.py` يولّد الشعار والأيقونات والخلفية بـ Pillow.
هذه رسوم برمجية (أشكال هندسية) وليست توليداً بنموذج صور: الشعار والأيقونة
يحتاجان حدوداً حادة وهندسة دقيقة، وموديل الانتشار يضيف ضبابية وغموضاً في الترخيص.

## الاختبارات

```bash
python3 -m pytest tests/ -q     # 32 اختباراً
```

الاختبارات تستخدم بيانات وهمية ثابتة ولا تلمس الشبكة ولا النموذج، فلا تستهلك
أي حصة ولا تتأثر بتعطّل مزوّد.

## حدود صادقة

- المقترح الفني قواعد بسيطة مكتوبة صراحةً (EMA/RSI/ATR/قمم وقيعان).
  **لا توجد بيانات نتائج، لذا لا يُذكر أي احتمال نجاح أو ربحية.** حقل
  `confidence` هو عدد الإشارات المتوافقة (0–3)، وليس احتمالاً.
- وقف الخسارة مشتق من ATR لا من رقم ثابت.
- النموذج 1.5B مناسب للتلخيص والالتزام بالعربية، وليس مُستنتِجاً متقدماً.
- هذا ليس نظام تنفيذ أوامر. لا اتصال بأي وسيط.
