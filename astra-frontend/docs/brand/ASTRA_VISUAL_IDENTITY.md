## Visual language
The reference establishes:

- cool light-gray / off-white light surfaces;
- silver/white geometric mark on dark backgrounds;
- restrained grayscale accents;
- large clean typography;
- generous spacing;
- institutional / aerospace / precision-tech mood;
- minimal decorative noise.
